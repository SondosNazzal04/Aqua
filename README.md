# 💧 Aqua
Aqua is an educational puzzle game designed to raise awareness about water usage and the importance of wise consumption to limit overconsumption.

## 🎮 How to Play
>Navigate: From the Start Menu, press Play or go to the Level Selection menu.

>Note: Currently, Level 1 is fully implemented as a functional prototype.

>Interact: Click on the pipe segments to rotate them.

>Goal: Connect the source to the tank without any open ends to complete the circuit and restore the water flow.

## 🛠️ Technical Details
-Engine: Unity

-Language: C#

>Focus: Logic mechanics, UI/UX flow, and Scene Management.
